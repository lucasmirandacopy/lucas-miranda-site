# Site do Lucas Miranda — instruções para o Claude

Este é o site pessoal do Lucas Miranda, copywriter de resposta direta.

## Como o projeto funciona
- Site estático: **um único arquivo `index.html`** + a pasta `assets/` (foto).
- Não tem build, framework nem dependências. Não instale nada no projeto.
- Hospedagem: **Vercel**, conectada a este repositório do **GitHub**. Todo `git push` na branch `main` publica o site automaticamente em ~1 minuto.

## Regras ao editar
- Mantenha a identidade visual: fundo papel `#EFE9DD`, tinta `#141C2B`, azul-tinta `#2C4A8F`, fontes Manrope + Inter + Newsreader itálica (só nas frases em destaque, classe `em`).
- Os pontos que o Lucas ainda precisa preencher estão marcados com comentários `EDITAR:` no HTML (WhatsApp, Instagram, portfólio, formulário da newsletter, nome da newsletter).
- Troca de foto: substitua `assets/foto.jpeg` mantendo o mesmo nome (formato quadrado ou retrato, mínimo 800 px).
- Depois de editar, mostre ao Lucas o que mudou e, com o OK dele, faça commit com uma mensagem clara em português e `git push`.
- Nunca apague seções inteiras sem o Lucas pedir.
